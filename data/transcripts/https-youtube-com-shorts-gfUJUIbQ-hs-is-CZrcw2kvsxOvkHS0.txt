Claude Code can now check its own code for security mistakes while it is writing it. Episode 119. The Security Guidance plugin is an official Claude Code plugin. Once installed, it reviews Claude's changes for common vulnerabilities in the same session. It checks at three points. After file edits, after each turn, and when Claude makes a commit or push. The first check is just pattern matching, so it adds no model cost. It looks for things beginners miss, injection, unsafe deserialization, unsafe DOM APIs, authorization bypass, weak crypto, and secrets accidentally landing in code. The useful part is custom rules. Add .claud slash claud securityguidance.md and tell it your project's risks, like do not log customer IDs or admin routes must check roles. Beginner rule. This is not a security guarantee. It is an early risk. Warning layer. Before code review and CI. Link in bio for the free Claude Code cheat sheet.
